# Challenge 3: Langflow Support Agent

## Challenge Overview
### Objective
Create a support agent for Langflow that assists users by answering questions and providing general information about the platform. This agent will use data available on GitHub, Langflow documentation, and the official website to provide accurate, relevant responses.

- **Input:** User questions, requests, and interactions about Langflow.
- **Output:** Responses and information generated by your agent.
- **Components:** Must include a chat input, chat output, and the Langwatch Evaluator for evaluation submissions.

---

### Evaluation Methodology
Your agent will be evaluated based on the following criteria:
1. **Answer Correctness:** Accuracy and relevance of responses.
2. **Execution Speed:** Swiftness in generating answers.
3. **Execution Cost:** Efficiency in computational resource usage.

---

## Repository Contents
- **Final Solution - Challenge 3.1.json**  
  The main flow, containing components for processing user questions, retrieving relevant information from Langflow resources, and generating answers.

- **Final Solution - Challenge 3.2.json**  
  The evaluation flow, which uses the `questions.csv` file for blind testing and iterates through the dataset, generating the output.

- **evaluation.csv**  
  A set of questions for blind testing and ground truth, which explains how accurate the model's responses are.

- **questions.csv**  
  A set of questions for blind testing. The responses generated during this test assess the agent’s generalization ability.
